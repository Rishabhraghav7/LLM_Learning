#### 4.2 Proposed architecture 


```mermaid
flowchart TD
    A["User NL Query"] --> B["Response Cache"]

    B -->|CACHE HIT| Z["Final Text Response"]
    B -->|CACHE MISS| C["Prompt Builder"]

    P["Static Prompt / System Instructions"] --> PC["LLM Prompt Cache"]
    PC --> C

    C --> D["Primary LLM"]
    D --> E["Structured Query"]
    E --> F["Validator"]

    F -->|VALID| G["Execute Query in MongoDB"]
    F -->|ERROR| H["Regenerate Query"]
    H --> D

    G --> I["MongoDB Query Result"]
    I --> J["Result Summarization"]

    J --> D2["Primary LLM"]
    PC --> D2
    D2 --> Z

    D -->|LLM Unavailable| K["Fallback LLM"]
    K --> E

    Z --> L["User"]
```


#### 4.3 Implemented architecture 

```mermaid 
flowchart TD

A["User NL Query"] --> B["Gemini<br/>Query Generator"]

B --> C["Structured Query"]

C --> D["Validator"]

D -->|VALID| E["Return Query"]
D -->|ERROR| F["Original NL<br/>Previous Query<br/>Validation Error<br/>Schema Context"]

F --> G["Gemini"]
G --> H["Corrected Query"]
H --> I["Validator"]

I -->|VALID| E
I -->|ERROR| J{"Retries < 3?"}

J -->|YES| F
J -->|NO| K["Return Error"]

E --> L["Gemini<br/>Summary Generator"]
L --> M["Summary / Natural Language Response"]

M --> N["Return Final Response"]
```
